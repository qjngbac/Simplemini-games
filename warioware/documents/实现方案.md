# WarioWare 式 microgame 合集 实现方案

## 1. 技术选型
- **前端**：HTML5 Canvas + 原生 JS（小游戏各自简单，可共用引擎）。
- **架构**：一个「宿主框架」管理 microgame 的加载、计时、胜负与节奏加速。
- **音频**：`howler.js` 循环 BGM + 各小游戏音效。

## 2. 目录结构
```
warioware/
├── index.html
├── style.css
└── src/
    ├── main.js           # 宿主：节奏、调度、计分
    ├── host.js           # microgame 接口契约、生命周期
    ├── loader.js         # 注册/随机抽取 microgame
    ├── microgames/
    │   ├── dodge.js      # 躲石头 3 秒
    │   ├── tap.js        # 点中目标
    │   ├── count.js      # 数几只猫
    │   ├── mash.js       # 狂按充能
    │   └── ...           # 更多小游戏
    └── ui.js             # 倒计时、提示、过场
```

## 3. 核心架构：宿主 + 微游戏契约
每个 microgame 实现统一接口：
```
Microgame = {
  id, title, prompt,           // 一句话指令
  init(ctx),                   // 初始化本关
  update(dt),                  // 每帧逻辑
  render(ctx),                 // 绘制
  onInput(type,data),          // 输入
  // 通过 ctx.win()/ctx.lose() 上报结果
}
```
宿主负责：显示指令 → 倒计时（初始 ~5s，逐关缩短）→ 收结果 → 计分 → 下一关。

## 4. 模块职责
| 模块 | 职责 |
|------|------|
| Host | 调度、计时、节奏加速、连胜计分、生命 |
| Loader | 注册所有 microgame，随机/顺序抽取 |
| Microgame | 各自 5 秒内的极简玩法 |
| UI | 大号指令文字、圆环倒计时、过场闪屏 |

## 5. 开发步骤
1. 宿主框架：状态（指令→进行→结算）、计时器、生命/连胜。
2. 定义 microgame 契约与生命周期（init/update/render/input/win/lose）。
3. 写 3~5 个示范 microgame（躲、点、数、按、拖）。
4. 随机抽取 + 节奏逐关加速（时间从 5s→1s）。
5. 指令大字 + 圆环倒计时 UI + 过场。
6. 失败扣命、命尽 Game Over、最高连胜记录。
7. 移动端触控适配（tap/拖拽/摇晃）。

## 6. 设计要点
- 每个 microgame **必须 5 秒内可懂可玩**，指令一句话。
- 共用输入抽象（tap/drag/key/mash），各小游戏只关心自身。
- 节奏加速是「笑点」来源：越后面越手忙脚乱。
