# 杀戮尖塔简化版 核心机制与算法

## 1. 卡牌数据驱动
```
Card = { id, name, cost, type, desc, effect(ctx) }
// effect 接收战斗上下文，修改 player/enemy/状态
```
新增卡牌只加数据 + effect 函数，不碰战斗主循环。

## 2. 牌库循环（回合制）
```
turnStart:
  energy = maxEnergy
  draw(5)            // 从抽牌堆取，不足则洗弃牌堆
playerPhase:
  出牌：若 energy>=cost → 执行 effect，energy-=cost，移到弃牌堆
  结束回合 → 弃掉手牌
enemyPhase:
  各敌人按意图执行
  状态结算（中毒掉血、回合计时）
turnEnd: 回到 turnStart
```
洗牌用 Fisher–Yates 保证随机均匀。

## 3. 敌人意图
每回合开始为敌人决定下一个行动并**展示意图图标**（攻击 X / 防御 / buff）：
```
intent = chooseIntent(enemy, turn)   // 可按模式或随机
显示：攻击类显示伤害值，便于玩家决策
enemyAct: 执行 intent 对应的行为
```

## 4. 状态效果（Status）
用 `Map<status, stacks>` 挂在 player/enemy 上：
- 中毒(poison)：回合结束扣 `stacks` 血，然后 stacks-1。
- 易伤(vulnerable)：受到攻击伤害 ×1.5，每回合 -1。
- 虚弱(weak)：造成攻击伤害 ×0.75，每回合 -1。
结算顺序：先状态结算再清减。

## 5. 伤害计算
```
dmg = base * (attacker.weak?0.75:1) * (target.vulnerable?1.5:1)
target.hp -= max(0, dmg - target.block)
block 在受击前抵消，回合开始清零（玩家）或按规则
```

## 6. 地图与进度
- 节点分层，每层随机若干节点，相邻层连边形成路径。
- 玩家沿路径前进，节点类型决定遭遇（战斗/奖励/休息/事件）。
- 进度与牌库、血量在节点间传递（run 状态）。

## 7. 胜负
- 战斗：敌人全部 hp<=0 胜；玩家 hp<=0 负（可重开 run）。
- Run：通关 1 层或击败 Boss 为通关。
