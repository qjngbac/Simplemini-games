# 杀戮尖塔简化版（Slay the Spire lite）实现方案

## 1. 技术选型
- **前端**：HTML/CSS/JS（DOM + Canvas 混合）。卡牌 UI 用 DOM 更易做，战斗数值用 JS。
- **状态管理**：单一游戏状态树 + 不可变更新（小项目可用普通对象 + 函数式 reducer）。
- **可选**：TypeScript 提升卡牌/事件类型安全。

## 2. 目录结构
```
slay-the-spire-lite/
├── index.html
├── style.css
└── src/
    ├── main.js          # 场景切换：地图/战斗/奖励/事件
    ├── cards.js         # 卡牌定义（数据驱动）
    ├── deck.js          # 抽牌/弃牌/洗牌
    ├── combat.js        # 战斗循环、能量、意图
    ├── enemy.js         # 敌人意图与行动
    ├── player.js        # 血量、能量、状态效果
    ├── relics.js        # 遗物（被动增益）
    ├── map.js           # 节点地图生成
    └── ui.js            # 卡牌渲染、拖拽、弹出
```

## 3. 核心系统
| 系统 | 职责 |
|------|------|
| Deck | 抽牌堆/手牌/弃牌堆/消耗堆，洗牌 |
| Combat | 回合制：玩家出牌(耗能)→敌人按意图行动 |
| Card | 数据驱动：`{cost, effect(state)}` |
| Enemy | 每回合生成「意图」（攻击/防御/ buff），按时行动 |
| Status | 中毒/虚弱/易伤等可叠加状态，回合结算 |
| Map | 分层节点（战斗/精英/商店/休息/事件），随机路径 |
| Reward | 战后选卡、掉遗物、回血 |

## 4. 开发步骤
1. 卡牌数据模型 + 渲染（DOM 卡面、费用、描述）。
2. 牌库循环：洗牌、抽 5、出牌耗能、弃牌、回合结束洗回。
3. 战斗：敌人意图显示 + 玩家出牌结算 + 敌人行动。
4. 状态效果系统（中毒每回合掉血、易伤增伤等）。
5. 胜负：敌人清空胜利，玩家血量 0 失败。
6. 地图节点生成与推进、战斗间奖励（选卡/回血/遗物）。
7. 遗物被动、精英/Boss、事件节点（简化）。
8. 拖拽出牌、移动端点选适配。

## 5. 简化边界
- 先做「单层战斗 + 线性 5~8 节点」即可玩；肉鸽地图后续扩展。
- 卡牌 20~40 张、敌人 5~8 种足够验证循环。
