# Baba Is You 类 核心机制与算法

## 1. 规则扫描（核心算法）
每步移动后，重算所有生效规则：
1. 收集所有文本实体及其位置（横向、纵向各自成行/列）。
2. 在每行/列找连续三元组 `(A)(IS)(B)`：
   - A 为 NOUN 文本，中间为 IS，B 为 PROPERTY 或 NOUN。
3. 仅当三元组**未被 STOP/墙体阻断**时计入规则。
4. 汇总得到：
   - `isYou: Set<type>`
   - `isWin: Set<type>`
   - `isPush: Set<type>`
   - `isStop: Set<type>`
   - `isSink/isMelt/...`
   - 转换规则 `X IS Y`（把 X 类型实体变成 Y）。

## 2. 移动与碰撞（基于规则属性）
输入方向 `d`：
```
youEntities = 所有 type∈isYou 的实体
尝试整体移动 youEntities：
  对每个 you 实体，沿 d 检查目标格：
    - 若目标有 isStop 实体且不可推 → 阻挡
    - 若目标有 isPush 实体 → 递归尝试推动链（推不动则停）
    - 否则移动
```
推动需检测「推动链」是否会撞墙/出界/推不动。

## 3. 特殊规则交互
- `X IS Y`（类型转换）：将 X 实体替换为 Y（保留位置）。
- `X IS EMPTY`：消除 X 自身（如 WALL IS EMPTY 让墙消失）。
- 多个冲突属性（如同时 YOU 与 STOP）：约定 YOU 优先可移动，或按扫描顺序最后生效者优先（需在文档固定优先级）。

## 4. 胜负判定
移动结算后：若存在 `type∈isYou` 实体与 `type∈isWin` 实体同格（或重叠区域）→ 过关。

## 5. 关卡数据格式
ASCII 网格，字符映射到对象/文本：
```
B = BABA文本(noun)   b = BABA实体
W = WALL文本         # = WALL实体
F = FLAG文本         * = FLAG实体
I = IS文本
Y = YOU文本  ...
```
关卡即字符串数组，加载时生成实体列表。

## 6. 撤销
每步前深拷贝实体状态入栈，支持撤销（教学关卡友好）。
