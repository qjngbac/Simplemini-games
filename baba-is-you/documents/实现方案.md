# Baba Is You 类规则解谜 实现方案

## 1. 技术选型
- **前端**：HTML5 Canvas + 原生 JS（网格回合制，性能无忧）。
- **规则引擎**：核心亮点，文本对象即规则，需设计为可解析/可重算的数据结构。
- **关卡**：用 ASCII 网格 + 对象图鉴定义，便于扩展与分享。

## 2. 目录结构
```
baba-is-you/
├── index.html
├── style.css
└── src/
    ├── main.js          # 主循环、输入
    ├── grid.js          # 网格、实体、坐标
    ├── rules.js         # 规则解析与重算（核心）
    ├── objects.js       # 对象类型、属性、图标
    ├── levels.js        # 关卡数据（ASCII 地图）
    └── render.js        # 绘制网格与实体
```

## 3. 核心概念
- **实体（Entity）**：可移动方块，带 `type`（如 BABA/WALL/ROCK/FLAG）与位置。
- **文本块（Text）**：`NOUN`（BABA）、`VERB`（IS）、`PROPERTY`（YOU/WIN/PUSH/STOP）。
- **规则**：当 `NOUN IS PROPERTY` 或 `NOUN IS NOUN` 三连文本横向/纵向相邻且未被阻断时生效。
- 玩家推动文本可改写规则（如把 `WALL IS STOP` 推散 → 墙不再阻挡）。

## 4. 模块职责
| 模块 | 职责 |
|------|------|
| Grid | 二维网格、实体增删、移动、碰撞（基于规则属性） |
| Rules | 每步后扫描文本三元组 → 重算当前生效规则集 |
| Objects | 类型→图标/属性映射 |
| Levels | ASCII 关卡 → 实体初始化 |
| Input | 方向键/触屏滑动移动「YOU」实体 |

## 5. 开发步骤
1. 网格 + 实体渲染 + 方向输入移动。
2. 文本块作为可推动实体（PLAY 文本本身也要能被推动）。
3. **规则引擎**：扫描横向/纵向相邻三元组，生成规则集（YOU/WIN/PUSH/STOP/SINK/MELT…）。
4. YOU 实体受输入移动，遵守 PUSH/STOP。
5. 胜负：任意 YOU 与 WIN 重叠 → 过关。
6. 关卡数据 + 多关卡切换 + 撤销/重开。
7. 移动端滑动输入 + 关卡选择。

## 6. 设计要点
- 规则是「每步重算」的，不是「事件触发」，避免状态不一致。
- 同一 NOUN 可多条规则（如 BABA IS YOU 且 BABA IS PUSH 冲突需规则优先级）。
