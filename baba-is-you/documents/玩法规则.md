# Baba Is You · 玩法规则

一款「文本即规则」的网格解谜游戏：你可以推动地上的文字块，改写世界运行的规则，从而打开原本走不通的路。

## 操作
- **移动**：方向键 或 `W A S D`，触屏可滑动。控制所有标着 `YOU` 的对象。
- **重开本关**：`R`
- **撤销一步**：`Z` 或 `U`（每步前自动存档，可连撤）
- **下一关**：过关后按 `N` / 空格 / 回车，或点「下一关」
- **关卡选择**：点「关卡选择」

## 核心机制
规则由三块（或四块，含 `NOT`）**相邻**的文字组成，横向或纵向皆可：

| 规则示例 | 含义 |
|---|---|
| `BABA IS YOU` | BABA 角色受你控制 |
| `WALL IS STOP` | 墙挡住移动（不可穿过） |
| `FLAG IS WIN` | 碰到旗子即过关 |
| `ROCK IS PUSH` | 石头可被推动 |
| `WATER IS SINK` | 任何物体进入水，两者一起消失 |
| `SKULL IS DEFEAT` | 碰到骷髅就消失 |
| `WALL IS ROCK` | 所有墙变成石头（类型转换，持续生效） |
| `WALL IS EMPTY` | 墙直接消失 |
| `BABA IS NOT YOU` | 否定：BABA 不再受控 |
| `ROCK IS MOVE` | 石头每回合自动沿上次方向滚动 |

要点：
- **规则每步重算**：推一下文字，规则当场改变，世界立刻不同。
- **文字块本身也能被推**（默认可推），所以你既能「组成」规则，也能「拆掉」规则。
- **STOP 优先于 PUSH**：既是 STOP 又是 PUSH 时，它依旧挡路。
- **推动链**：多个 PUSH 物体连成一排，会一起被推或一起卡住。
- 文字块排成一行时，若中间被 STOP 物体挡住，该规则失效。

## 关卡清单（共 12 关，均已用 BFS 严格求解器证明可解、且胜利严格依赖改写规则）

### 第一阶段：基础教学
1. **第一关：旗子变胜利** — 旗子初始并非胜利目标：把 `N(WIN)` 向上推到 `FLAG IS` 后面拼出 `FLAG IS WIN`，再触碰旗子。
2. **第二关：拆墙开路** — 墙壁（`WALL IS STOP`）封死道路：先推开 `S(STOP)` 破坏规则使墙壁失效，穿墙拼出 `FLAG IS WIN` 碰旗。
3. **第三关：墙即胜利** — 场上没有旗子：把 `N(WIN)` 拼到 `WALL IS` 后面组成 `WALL IS WIN`，直接撞墙获胜。

### 第二阶段：进阶转换
4. **第四关：移石填海** — `WATER IS SINK` 吞没一切：把石头 `o` 推进深水 `~` 填平道路，拼出 `FLAG IS WIN`。
5. **第五关：墙化作石** — 整排厚墙封锁：把 `O(ROCK)` 拼到 `WALL IS` 后面组成 `WALL IS ROCK` 将墙变成可推石头，推开石头过关。
6. **第六关：虚无抹除** — 拼出 `WALL IS EMPTY` 瞬间消除阻挡墙体，随后拼出 `FLAG IS WIN` 到达终点。

### 第三阶段：危险与否定
7. **第七关：骷髅危机** — `SKULL IS DEFEAT` 触碰即死：推开 `C(DEFEAT)` 破坏致命规则，安全穿过骷髅群碰到旗子。
8. **第八关：否定之力** — 引入 `NOT` 前缀：把 `X(NOT)` 推入组成 `SKULL IS NOT DEFEAT`，骷髅便不再危险。
9. **第九关：自动行者** — 引入 `MOVE` 属性：给石头加上 `ROCK IS MOVE`，让它自动向前移动填入深水开辟通路。

### 第四阶段：大师与综合
10. **第十关：灵魂出窍** — 深水阻隔且无法填平：把 `Y(YOU)` 推到 `ROCK IS` 后面组成 `ROCK IS YOU`，直接控制对岸的石头碰旗。
11. **第十一关：绝处逢生** — 多重阻碍：先拆开 `WALL IS STOP` 穿墙，再推石头填平深水河，最后拼出 `FLAG IS WIN` 通关。
12. **第十二关：终极试炼** — 终极挑战：将墙壁化为石头 (`WALL IS ROCK`)，推石头填深水开路，最后拼出 `FLAG IS WIN` 夺取最终胜利！

> 提示：每关顶部「当前生效规则」会实时显示，通关思路往往就在其中。
