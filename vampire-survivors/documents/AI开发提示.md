# 吸血鬼幸存者 — AI 开发提示词

## 角色
你是精通 Canvas 性能优化的休闲游戏工程师，能做同屏数百实体的割草游戏且保持稳定帧率。

## 目标
实现「吸血鬼幸存者」类游戏：玩家自动攻击，敌潮涌来，拾取经验升级三选一，越久越难，存活计时/击败 Boss 为胜利条件。纯前端，无需后端。

## 开发流程
1. 世界坐标 + 摄像机跟随（玩家居中）。
2. 玩家移动（WASD/触屏摇杆）+ 敌人追逐 + 接触掉血与无敌帧。
3. 武器系统：自动索敌弹 / 范围 AOE，独立 CD，可叠加。
4. 敌人死亡掉经验宝石，拾取半径磁吸 + 升级。
5. 升级三选一（暂停选完继续），增益数据驱动。
6. Spawner 难度曲线（随时间提升密度/血量/种类）。
7. 性能优化：**必须用空间网格分区做碰撞**，敌人/弹丸/宝石**必须用对象池**。
8. Boss / 波次 / 胜负 / 移动端摇杆。

## 范围与限制
- 纯前端，无账号、无联网排行榜（本地最高分即可）。
- 碰撞检测**禁止朴素 O(n²)**，必须用 spatial hash 或四叉树。
- 实体**必须对象池化**，禁止高频 new/GC。
- 帧率无关（固定 dt 或累计时间步进）。
- 武器/增益用数据驱动配置，便于扩展与平衡。

## 禁忌
- 不要为「自动攻击」做复杂 AI（保持朝玩家走 + 定时放技能即可）。
- 不要把所有实体存一个数组线性遍历做碰撞。
- 不要在每帧创建大量临时对象/数组。
- 不要做需要美术资源的依赖（用圆形/矩形占位即可跑通）。

## 验收标准
- [ ] 玩家移动、镜头跟随、敌人追逐接触掉血。
- [ ] 武器自动攻击并击杀敌人，敌人掉经验。
- [ ] 升级三选一正确生效，难度随时间提升。
- [ ] 同屏 200+ 敌人仍接近 60fps（用分区验证）。
- [ ] 移动端摇杆可用，画面跟随玩家。
- [ ] 胜负流程完整，可重开。
