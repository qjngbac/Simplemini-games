# 吸血鬼幸存者 核心机制与算法

## 1. 世界与摄像机
- 世界坐标 `(wx, wy)`，玩家位置 `P`。摄像机偏移 `cam = P - screenCenter`。
- 渲染时所有实体减 `cam` 得到屏幕坐标。
- 输入方向在世界系：摇杆/ WASD → 归一化向量 × speed × dt。

## 2. 敌人 AI（追逐）
```
dir = normalize(P - E.pos)
E.pos += dir * E.speed * dt
```
接触伤害：每帧检测 `dist(P,E) < P.r + E.r` → 玩家扣血（可加无敌帧）。

## 3. 武器自动攻击
两类常用：
- **索敌弹**：每 `cd` 秒选最近敌人（或最近 K 个），生成弹丸飞向其当前位置。
- **范围 AOE**：以玩家为中心半径 `R` 的持续/脉冲伤害。
多武器各自独立计时，叠加生效。

## 4. 碰撞优化（高性能关键）
同屏敌人数百，朴素 O(n²) 会卡。用**均匀网格分区（spatial hash）**：
- 世界按 `cellSize` 分格，实体登记到所在格。
- 查询某实体附近敌人只看相邻 9 格。
- 弹丸命中同理。

## 5. 经验与升级
- 敌人死亡掉 `Gem(wx,wy,exp)`；玩家拾取半径内宝石磁吸。
- 经验达阈值 → 升级，弹出三选一（随机增益：新武器/加伤/加速/加血）。
- 增益为数据驱动：`{id, apply(state)}`，便于扩展。

## 6. 对象池
敌人/弹丸/宝石大量创建销毁，用池复用避免 GC 卡顿：
```
pool = []  // 空闲
get(): pool.pop() || new Entity()
free(e): e.reset(); pool.push(e)
```

## 7. 难度曲线
`spawnRate(t)` 与 `enemyHP(t)` 随存活时间 `t` 增长，控制「前期爽、后期难」。
