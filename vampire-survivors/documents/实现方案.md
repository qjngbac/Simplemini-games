# 吸血鬼幸存者（Vampire Survivors 类）实现方案

## 1. 技术选型
- **前端**：HTML5 Canvas + 原生 JS（推荐），大量实体需用对象池与空间优化。
- **物理/碰撞**：自写简单圆形碰撞（距离 < r1+r2），无需重物理引擎。
- **音频**：`howler.js`（循环 BGM + 音效）。
- **可选**：TypeScript + Vite 提升可维护性（中等项目建议）。

## 2. 目录结构
```
vampire-survivors/
├── index.html
├── style.css
└── src/
    ├── main.js          # 启动、主循环
    ├── player.js        # 玩家：移动、等级、属性
    ├── enemy.js         # 敌人工厂 + 对象池
    ├── weapon.js        # 武器/弹幕（自动攻击）
    ├── spawner.js       # 波次与刷怪
    ├── xp.js            # 经验宝石 + 升级
    ├── upgrade.js       # 升级三选一
    └── camera.js        # 镜头跟随 + 世界坐标
```

## 3. 核心系统
| 系统 | 职责 |
|------|------|
| Player | WASD/摇杆移动，血量，等级，拾取范围 |
| Spawner | 按时间/分数提升刷怪密度与种类 |
| Enemy | 朝玩家移动，接触造成伤害，死亡掉经验 |
| Weapon | 自动索敌/范围攻击，多武器叠加 |
| XP | 宝石掉落、磁吸、拾取升级 |
| Upgrade | 升级暂停 → 三选一增益 |
| Camera | 以玩家为中心的世界滚动渲染 |

## 4. 开发步骤
1. 世界坐标 + 摄像机跟随（玩家始终居中）。
2. 玩家移动 + 简单敌人追逐 + 接触掉血。
3. 武器自动攻击（如最近的 N 个敌人发射弹丸 / 周围 AOE）。
4. 敌人死亡掉经验宝石，拾取升级。
5. 升级三选一 UI（暂停选完继续）。
6. Spawner 难度曲线（时间越久越密越强）。
7. 多武器叠加、Boss、波次、胜负（存活计时/击败 Boss）。
8. 性能优化：对象池、碰撞用网格分区、限制同屏数量。

## 5. 难度与手感
- 前期「割草爽感」靠高频低伤；后期靠武器组合与走位。
- 关键调参：刷怪率、敌人速度、武器 CD、伤害、经验曲线。
