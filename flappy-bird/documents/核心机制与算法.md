# 像素鸟 核心机制与算法

## 1. 物理模型（帧率无关）
使用固定时间步长 `dt`（如 1/60 秒），避免不同设备速度不同：
```
vy += g * dt
y  += vy * dt
```
拍翅时：`vy = flapImpulse`（负值向上）。落地 `y >= groundY` 即死亡。

## 2. 管道生成
- 每隔固定水平距离 `spacing` 生成一对上下管。
- 间隙中心高度 `gapY` 在 `[minY, maxY]` 内随机，限制相邻变化幅度，避免突变。
- 管道从右侧进入，以 `speed` 向左滚动；完全移出左侧后回收/复用（对象池）。
- 过管判定：鸟 x 越过管道 x 且未碰撞 → 计分 +1。

## 3. 碰撞检测（AABB）
鸟视作矩形 `(bx, by, bw, bh)`，管道视作两个矩形（上管、下管）：
```
碰撞 = 矩形相交(bx,by,bw,bh, pipeRect)
```
相交条件：鸟右 > 管左 且 鸟左 < 管右 且 鸟底 > 管顶 且 鸟顶 < 管底。
任一管道或地面相交 → gameover。

## 4. 状态机
```
ready  --flap--> playing
playing --碰撞--> gameover
gameover --tap--> ready（重置）
```

## 5. 响应式渲染
- 逻辑分辨率固定（如 360×640），绘制到内部 canvas。
- CSS 用 `width:100%; max-width; aspect-ratio` 等比缩放，保证手机/桌面一致手感。
- 输入坐标需映射到逻辑坐标（触屏直接触发 flap，无需坐标）。

## 6. 难度递增（可选）
随时间缓慢提升 `speed` 或缩小 `gap`，制造紧张感；注意保留“可完成”底线。
