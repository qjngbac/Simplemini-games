# 像素鸟（Flappy Bird 简化版）实现方案

## 1. 技术选型
- **纯前端**：HTML5 + Canvas + 原生 JavaScript（vanilla），无需框架、无需后端。
- **渲染**：`requestAnimationFrame` 驱动游戏循环，固定时间步长避免帧率波动影响物理。
- **输入**：键盘（空格/↑）与触屏（tap）双支持，统一抽象为 `flap()` 事件。
- **音效（可选）**：Web Audio API 简单合成，或 `howler.js`。

## 2. 目录结构（单文件优先，可拆分）
```
flappy-bird/
├── index.html          # 画布 + 入口
├── style.css           # 页面与画布样式、移动端适配
└── game.js             # 全部逻辑（小项目可单文件）
```
进阶拆分：`src/bird.js` `src/pipes.js` `src/loop.js` `src/input.js` `src/state.js`。

## 3. 模块划分
| 模块 | 职责 |
|------|------|
| GameLoop | 固定步长更新 + 渲染，管理状态切换 |
| Bird | 位置、速度、重力、拍翅冲量、绘制 |
| Pipes | 成对生成、水平滚动、随机间隙高度、回收 |
| Collision | 鸟与管道/地面的 AABB 碰撞检测 |
| Score | 过管 +1，最高分存 `localStorage` |
| State | ready / playing / gameover 三态机 |
| Input | 键鼠/触屏 → `flap()` |

## 4. 开发步骤
1. 搭 HTML 画布 + 自适应缩放（逻辑分辨率固定，CSS 等比缩放）。
2. 实现 GameLoop（update/render 分离）。
3. Bird 重力与拍翅，先让鸟能飞、能落地。
4. Pipes 生成与滚动，调试间距与速度手感。
5. 碰撞检测 + 游戏结束流程（显示分数、重开）。
6. 计分、最高分、简单美术（圆/矩形即可）与音效。
7. 移动端触屏适配与防误触。

## 5. 关键调参（手感来源）
- 重力 `g`、拍翅初速度 `flapV`、管道间隙 `gap`、管道水平间距 `spacing`、滚动速度 `speed`。
- 建议先用经典值，再微调让难度曲线平滑。
