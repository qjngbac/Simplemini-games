# Peglin 弹珠肉鸽 实现方案

## 1. 技术选型
- **前端**：HTML5 Canvas + 物理引擎 **matter.js**（弹珠碰撞、反弹、重力）。
- **渲染**：matter.js 自带 Render 或自绘；UI（血条、卡牌、球袋）用 DOM 叠层。
- **音效**：`howler.js`（弹珠撞击、升级）。

## 2. 目录结构
```
peglin/
├── index.html
├── style.css
├── lib/matter.min.js
└── src/
    ├── main.js          # 启动、场景（战斗/奖励/Boss）
    ├── board.js         # 钉子布局、球袋（敌怪）
    ├── ball.js          # 弹珠发射、物理属性
    ├── combat.js        # 伤害结算、敌人血量、回合
    ├── orbs.js          # 法球（弹珠增益，数据驱动）
    ├── upgrades.js      # 局内三选一升级
    └── ui.js            # 血条/能量/卡牌 DOM
```

## 3. 核心系统
| 系统 | 职责 |
|------|------|
| Board | 生成钉子网格/随机布点 + 敌人(Boss)球袋 |
| Ball | 玩家点击发射弹珠，物理反弹，命中扣敌血 |
| Orbs | 法球附加效果（多重弹/穿透/燃烧…），可叠加 |
| Combat | 敌人血量，弹珠伤害，清场胜利 |
| Upgrades | 每波后三选一（新法球/伤害/弹数） |
| Boss | 大球袋多血，需多波弹珠 |

## 4. 开发步骤
1. matter.js 世界 + 重力 + 边界（漏斗形弹珠台）。
2. 生成钉子（静态圆形 body）与底部敌人球袋（带血量）。
3. 点击/触屏从顶部发射弹珠，物理反弹下落。
4. 弹珠命中钉子/敌人 → 伤害结算（敌人血条）。
5. 敌人清空 → 波次推进 + 三选一升级（法球/增益）。
6. 法球系统：发射多颗、附加元素伤害、暴击等。
7. Boss 波 + 胜负 + 移动端点击发射。

## 5. 手感与平衡
- 钉子密度、弹性系数、重力共同决定弹道随机性与爽感。
- 法球组合是肉鸽深度来源（如「多重弹 + 燃烧 + 穿透」）。

## 6. 物理注意
- 用 `isStatic` 钉子，`restitution` 控制弹性。
- 弹珠用圆形 body；敌人球袋可设为静态大圆，命中即扣血并移除/标记。
