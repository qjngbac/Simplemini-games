# Peglin 弹珠肉鸽 核心机制与算法

## 1. 物理世界（matter.js）
```
engine = Matter.Engine.create()
engine.gravity.y = 1            // 向下重力
// 边界：左右下为静态矩形；顶部开口供发射
// 钉子：Matter.Bodies.circle(x,y,r,{isStatic:true, restitution:0.6})
// 弹珠：Matter.Bodies.circle(px,py,br,{restitution:0.7, friction:0})
```
每帧 `Engine.update(engine, dt)`。

## 2. 发射弹珠
- 玩家在顶部选定 x（或固定中点），点击发射。
- 赋予初速度向下 + 微小随机水平扰动（增加变化）。
- 弹珠进入世界后受重力与碰撞自然弹道。

## 3. 碰撞与伤害
监听 `collisionStart`：
```
Matter.Events.on(engine,'collisionStart',(e)=>{
  for pair in e.pairs:
    if 一方是弹珠 且 另一方是敌人球袋:
       damageEnemy(敌方, ball.dmg)
    if 一方是弹珠 且 另一方是钉子:
       onPegHit(peg)   // 钉子可被点亮/计分
})
```
- 敌人球袋 `hp -= dmg`；`hp<=0` → 移除并判定清场。
- 弹珠落到底部边界 → 回收入池，准备下一发。

## 4. 法球（Orb）增益系统
数据驱动：
```
Orb = { id, name, onFire(ballCtx), mods:{dmg,multishot,crit,...} }
```
- `multishot`：每次发射 N 颗（不同 x 偏移）。
- `crit`：概率 ×倍率。
- `burn`：命中附加持续伤害。
发射时按已解锁 orbs 组合生成弹珠属性。

## 5. 局内成长（三选一）
每波结束暂停，随机给 3 个选项：
- 新法球 / 伤害 +X% / 弹数 +1 / 暴击率 / 穿透。
选项即 `apply(runState)`，数据驱动便于扩展。

## 6. 波次与 Boss
- 普通波：若干小球袋，清空进奖励。
- Boss 波：1 个大球袋高血，需持续输出。
- 胜负：全清通关 / 玩家能量(生命)耗尽失败（弹珠未清敌会扣能量）。

## 7. 对象池
弹珠复用：飞出底部 → `Matter.World.remove` 并放回池，发射时 `add` 并设初速。
