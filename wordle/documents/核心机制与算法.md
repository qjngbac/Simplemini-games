# Wordle 核心机制与算法

## 1. 判定算法（关键）
对猜测 `guess` 与答案 `answer`（等长）：
1. 先标记「绿」：位置 i 相同 → 绿，消耗掉该答案字母计数。
2. 再标记「黄/灰」：位置不同的字母，若答案剩余计数 > 0 → 黄，并减计数；否则灰。
```
counts = 统计 answer 各字母出现次数
result = 全灰
for i in 0..n:
  if guess[i]==answer[i]: result[i]=GREEN; counts[guess[i]]--
for i in 0..n:
  if result[i]==GREEN: continue
  c=guess[i]
  if counts[c]>0: result[i]=YELLOW; counts[c]--
  else: result[i]=GRAY
```
注意：黄只在实际剩余出现时才给，避免重复字母误判。

## 2. 键盘状态合并
每个字母取历史最优：绿 > 黄 > 灰。已绿/黄过的字母不再回退为灰。

## 3. 胜负
- 任一行全绿 → 胜利。
- 6 行用完仍非全绿 → 失败，展示答案。

## 4. 每日一词（可选）
用日期字符串做种子，从答案池取固定索引，保证当天所有人同词：
```
seed = dateString
index = hash(seed) % answerPool.length
```

## 5. 数据结构
- `answerPool: string[]` 答案候选。
- `validGuesses: Set<string>` 合法输入（含答案池）。
- 棋盘状态：`rows: {letters:string[], states:State[]}[]`。

## 6. 动画与可访问性
- 翻牌动画用 CSS transition + 错峰 delay。
- 着色避免只用颜色（色盲）：可加图案/符号区分。
