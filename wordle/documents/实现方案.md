# Wordle 猜词 实现方案

## 1. 技术选型
- **纯前端**：HTML + CSS + 原生 JS。无 Canvas 需求，DOM 网格即可。
- **词库**：内置一个英文 5 字母常用词表（答案池 + 合法猜测池），可放 `words.js`。
- **可选中文版**：改为「成语/词语」猜字，逻辑相同，词库换中文。
- **持久化**：当日进度与战绩存 `localStorage`；可选每日一词（按日期选词）。

## 2. 目录结构
```
wordle/
├── index.html      # 网格、键盘、弹窗
├── style.css       # 配色（绿/黄/灰）、动画
├── words.js        # 答案词 + 合法词集合
└── game.js         # 状态、判定、交互
```

## 3. 模块划分
| 模块 | 职责 |
|------|------|
| WordBank | 答案池、合法词校验 |
| Board | 6×5 格子渲染与状态着色 |
| Keyboard | 屏幕键盘 + 物理键盘输入、字母状态 |
| Judge | 比对猜测与答案，输出每格颜色 |
| State | 当前行、列、游戏结束/胜利、每日词 |
| Storage | 进度与统计持久化 |

## 4. 开发步骤
1. 词库接入（先 200~1000 词即可跑通）。
2. 渲染 6×5 网格与键盘。
3. 输入逻辑：字母填入、退格、回车提交。
4. Judge 判定着色（绿=位置对，黄=存在错位置，灰=无）。
5. 键盘字母状态联动（取最优着色）。
6. 胜负判定、重开、每日一词（可选）。
7. 动画（翻牌）+ 战绩统计 + 移动端适配。

## 5. 难度与扩展
- 难度：词长可变（4/5/6）、无限模式 vs 每日模式。
- 扩展：分享结果（ emoji 方块）、提示、连胜统计。
